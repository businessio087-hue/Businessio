# 19th Hole Putt-Putt Website

A professional, high-contrast marketing landing page for **19th Hole Putt-Putt** in Pretoria East.

## 🚀 Features
- **Modern UI**: Glassmorphism effects and a responsive layout using Tailwind CSS.
- **Interactive Elements**: Alpine.js for state management, booking modals, and a dynamic image gallery.
- **Animations**: AOS (Animate On Scroll) for elegant entrance effects and custom CSS keyframes for a unique preloader.
- **Lead Generation**: Integrated WhatsApp reservation system.
- **Accessibility**: Fully responsive design and disability-friendly callouts.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS** (Styling)
- **Alpine.js** (Interactivity)
- **AOS** (Animations)
- **Google Maps API** (Location Embedding)

## 📂 Project Structure
- `index.html`: Main entry point.
- `css/style.css`: Custom styles and animations.
- `js/app.js`: Core UI logic and background shifts.
- `js/booking.js`: Reservation handling.
- `assets/`: Media assets (videos, etc.).

Add the background video as `assets/putt-putt-background.mp4`. The page falls back to its existing gradient background if the video is unavailable.

## 🌐 Deployment
This project is optimized for **GitHub Pages**. Simply push the code to a GitHub repository and enable Pages in the settings.
